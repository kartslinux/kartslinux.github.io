📘 Technical Guide & Package Overview

  • linux-image-*.deb / kernel-*.rpm: Core compiled kernel (vmlinuz) and modules.
  • linux-headers-*.deb / kernel-headers-*.rpm: C header files required for compiling out-of-tree drivers.
  • vmlinuz-*: Raw standalone kernel binary for custom bootloaders or embedded boards.

Note: Hardened server profiles intentionally omit desktop drivers to minimize the attack surface.
