📘 Technical Guide & Package Overview / Szakmai Tájékoztató

  • linux-image-*.deb / kernel-*.rpm: The core compiled Linux kernel (vmlinuz) and modules. Automatically updates GRUB and initramfs upon installation.
  • linux-headers-*.deb / kernel-devel-*.rpm: C header files required only if you compile external out-of-tree kernel modules (e.g., NVIDIA proprietary drivers, VirtualBox, ZFS). Not needed for monolithic server kernels.
  • vmlinuz-*: Raw standalone kernel binary for custom bootloaders, embedded devices, or specialized OS builds.

Why specialized kernels? Removing unused drivers and subsystems drastically reduces the attack surface (enhancing cybersecurity) and lowers RAM/CPU overhead. Conversely, a hardened server kernel will intentionally lack desktop hardware support (Wi-Fi, sound, 3D graphics). Always verify the catalog description before deployment.
